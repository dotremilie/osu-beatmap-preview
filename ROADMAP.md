# Roadmap

## Skinning

- Make the current procedural Argon appearance the built-in default skin.
- Add a skinning API for consumer skin selection and assets, keeping drawable models and ruleset extension contracts internal.
- Support visible slider tails through skins that provide them. The default Argon skin intentionally has no tail circle.

Skinning and visible slider tails are subsequent work, outside the autoplay cursor feature.
